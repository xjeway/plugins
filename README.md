# plugins

Jeway's Claude Code plugins, published as a single marketplace.

```bash
claude plugin marketplace add xjeway/plugins   # or a local clone: ~/Code/plugins
claude plugin install merge-steward@plugins
```

| Plugin | Status | What it does |
|---|---|---|
| [merge-steward](plugins/merge-steward) | In progress | A steward session serializes merges from many parallel sessions into an integration branch. |
